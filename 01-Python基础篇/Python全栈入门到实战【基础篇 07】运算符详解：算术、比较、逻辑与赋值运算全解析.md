# 二、算术运算符：数值计算的核心
算术运算符用于处理**数值型数据**（整数、浮点数）的计算，返回一个数值结果，是最基础、最常用的运算符。

## 1. 算术运算符分类与语法
| 运算符 | 名称         | 语法     | 示例           | 说明                                   |
| ------ | ------------ | -------- | -------------- | -------------------------------------- |
| `+`    | 加法         | `a + b`  | `10 + 5 → 15`  | 数值相加；字符串拼接；列表合并         |
| `-`    | 减法         | `a - b`  | `10 - 5 → 5`   | 数值相减                               |
| `*`    | 乘法         | `a * b`  | `10 * 5 → 50`  | 数值相乘；字符串/列表重复              |
| `/`    | 除法         | `a / b`  | `10 / 5 → 2.0` | 结果始终是浮点数，除数不能为0          |
| `//`   | 整除         | `a // b` | `10 // 3 → 3`  | 取商的整数部分，向下取整               |
| `%`    | 取模（余数） | `a % b`  | `10 % 3 → 1`   | 取除法的余数，常用于判断奇偶、循环周期 |
| `**`   | 幂运算       | `a ** b` | `2 ** 3 → 8`   | a的b次方，等价于`pow(a,b)`             |

## 2. 实操示例
```python
# 基础算术运算
a = 10
b = 3

print(f"加法：{a} + {b} = {a + b}")          # 输出：13
print(f"减法：{a} - {b} = {a - b}")          # 输出：7
print(f"乘法：{a} * {b} = {a * b}")          # 输出：30
print(f"除法：{a} / {b} = {a / b}")          # 输出：3.3333333333333335（浮点数）
print(f"整除：{a} // {b} = {a // b}")        # 输出：3（向下取整）
print(f"取模：{a} % {b} = {a % b}")          # 输出：1（余数）
print(f"幂运算：{a} ** {b} = {a ** b}")      # 输出：1000

# 特殊用法：+/* 用于非数值类型
print("字符串拼接：" + "Hello" + "Python")   # 输出：HelloPython
print("字符串重复：" + "Hi" * 3)             # 输出：HiHiHi
print("列表合并：", [1,2] + [3,4])           # 输出：[1,2,3,4]
print("列表重复：", [0] * 5)                 # 输出：[0,0,0,0,0]
```

## 3. 核心避坑要点
### 坑1：除法除数为0
- 报错：`ZeroDivisionError: division by zero`；
- 原因：用`/`/`//`/`%`时，除数`b=0`；
- 解决：计算前判断除数是否为0：
  ```python
  b = 0
  if b != 0:
      print(10 / b)
  else:
      print("除数不能为0！")
  ```

### 坑2：浮点数精度误差
- 问题：`0.1 + 0.2 = 0.30000000000000004`（二进制存储浮点数的精度问题）；
- 解决：
  1. 简单场景：用`round()`保留指定小数位：`round(0.1+0.2, 2) → 0.3`；
  2. 高精度场景：用`decimal`模块：
     ```python
     from decimal import Decimal
     print(Decimal("0.1") + Decimal("0.2"))  # 输出：0.3
     ```

### 坑3：整除向下取整（负数场景）
- 易错点：`-10 // 3 → -4`（不是-3，因为向下取整）；
- 验证：
  ```python
  print(-10 // 3)  # 输出：-4
  print(-10 % 3)   # 输出：2（余数公式：a = (a//b)*b + a%b → -10 = (-4)*3 + 2）
  ```

## 4. 适用场景
- 数值计算：平均分、总分、BMI指数、几何计算；
- 数据处理：判断奇偶（`num % 2 == 0`为偶数）、循环周期（`i % 5 == 0`每5次执行一次）；
- 字符串/列表操作：拼接、重复、合并。


# 三、比较运算符：条件判断的基础
比较运算符用于判断两个数据之间的**关系**，返回一个**布尔值（True/False）**，是`if`判断、循环条件的核心。

## 1. 比较运算符分类与语法
| 运算符 | 名称     | 语法     | 示例              | 说明                           |
| ------ | -------- | -------- | ----------------- | ------------------------------ |
| `==`   | 等于     | `a == b` | `10 == 10 → True` | 判断值是否相等，注意是两个等号 |
| `!=`   | 不等于   | `a != b` | `10 != 5 → True`  | 判断值是否不相等               |
| `>`    | 大于     | `a > b`  | `10 > 5 → True`   | 数值比较；字符串按ASCII码比较  |
| `<`    | 小于     | `a < b`  | `10 < 5 → False`  | 同上                           |
| `>=`   | 大于等于 | `a >= b` | `10 >= 10 → True` | 大于或等于，满足其一即True     |
| `<=`   | 小于等于 | `a <= b` | `10 <= 5 → False` | 小于或等于，满足其一即True     |

## 2. 实操示例
```python
# 数值比较
score = 85
pass_line = 60
excellent_line = 90

print(f"是否及格：{score >= pass_line}")    # 输出：True
print(f"是否优秀：{score >= excellent_line}")# 输出：False
print(f"是否等于85：{score == 85}")        # 输出：True
print(f"是否不等于90：{score != 90}")       # 输出：True

# 字符串比较（按ASCII码，字母a-z对应97-122，A-Z对应65-90）
print(f"'a' > 'A' → {'a' > 'A'}")          # 输出：True（97>65）
print(f"'abc' < 'abd' → {'abc' < 'abd'}")  # 输出：True（逐字符比较，第三个字符c<d）

# 列表/元组比较（逐元素比较）
print(f"[1,2] < [1,3] → {[1,2] < [1,3]}")  # 输出：True
print(f"(10,20) == (10,20) → {(10,20) == (10,20)}") # 输出：True
```

## 3. 核心避坑要点
### 坑1：混淆`==`和`=`
- 错误：`if score = 60:`（赋值运算符，不是比较）；
- 正确：`if score == 60:`（比较运算符）；
- 原因：`=`是赋值（给变量存值），`==`是比较（判断值是否相等），新手最易混淆！

### 坑2：不同类型数据比较
- 报错：`TypeError: '>' not supported between instances of 'int' and 'str'`；
- 原因：试图比较整数和字符串（比如`10 > "5"`）；
- 解决：先统一类型（比如`10 > int("5")`）。

### 坑3：浮点数比较相等
- 问题：`0.1 + 0.2 == 0.3 → False`（精度误差）；
- 解决：判断差值是否小于极小值（如`1e-9`）：
  ```python
  a = 0.1 + 0.2
  b = 0.3
  print(abs(a - b) < 1e-9)  # 输出：True（abs是绝对值）
  ```

## 4. 适用场景
- 条件判断：`if`/`while`的条件表达式；
- 数据筛选：筛选及格学生、成年用户、价格低于100的商品；
- 数据验证：验证输入值是否符合要求（如年龄>=0）。


# 四、逻辑运算符：多条件组合的关键
逻辑运算符用于**组合多个比较条件**，返回布尔值，实现“且/或/非”的复杂逻辑判断，是处理多条件的核心。

## 1. 逻辑运算符分类与语法
| 运算符 | 名称   | 语法      | 逻辑规则                                         | 示例                                 |
| ------ | ------ | --------- | ------------------------------------------------ | ------------------------------------ |
| `and`  | 逻辑与 | `a and b` | 两者都为True，结果才为True；否则False            | `score>=60 and age>=18 → 及格且成年` |
| `or`   | 逻辑或 | `a or b`  | 两者有一个为True，结果就为True；都为False才False | `score>=90 or is_vip → 优秀或VIP`    |
| `not`  | 逻辑非 | `not a`   | 取反：True变False，False变True                   | `not (score<60) → 不是不及格`        |

## 2. 核心特性：短路求值
逻辑运算符会“短路”——只要能确定最终结果，就不再计算后续条件，这能提升效率，也会影响代码执行：
- `and`短路：如果第一个条件为False，直接返回False，不计算第二个条件；
- `or`短路：如果第一个条件为True，直接返回True，不计算第二个条件。

## 3. 实操示例
```python
# 基础逻辑运算
age = 20
score = 85
is_vip = True

# and：且（都满足才True）
print(f"成年且及格：{age >= 18 and score >= 60}")  # 输出：True
print(f"成年且优秀：{age >= 18 and score >= 90}")  # 输出：False

# or：或（满足一个就True）
print(f"优秀或VIP：{score >= 90 or is_vip}")       # 输出：True
print(f"未成年或不及格：{age < 18 or score < 60}") # 输出：False

# not：非（取反）
print(f"不是VIP：{not is_vip}")                   # 输出：False
print(f"不是不及格：{not (score < 60)}")           # 输出：True

# 短路求值示例
a = 0
# and短路：第一个条件False，第二个条件（a+=1）不会执行
False and (a += 1)
print(f"a的值：{a}")  # 输出：0

# or短路：第一个条件True，第二个条件（a+=1）不会执行
True or (a += 1)
print(f"a的值：{a}")  # 输出：0
```

## 4. 核心避坑要点
### 坑1：逻辑运算符优先级
- 易错点：`not a and b` 等价于 `(not a) and b`，不是`not (a and b)`；
- 优先级：`not` > `and` > `or`，不确定就加括号：
  ```python
  # 加括号更清晰
  print((not is_vip) and (score >= 60))
  ```

### 坑2：用`and/or`代替`if`
- 错误：`score >= 60 and print("及格")`（依赖短路求值，可读性差）；
- 正确：`if score >= 60: print("及格")`（语义清晰）；
- 避坑：逻辑运算符用于**判断条件**，不是替代流程控制。

## 5. 适用场景
- 复杂条件判断：“成年且及格”“优秀或VIP”“不是未成年且不是不及格”；
- 数据筛选：筛选“价格<100且评分>=4.5”的商品；
- 权限控制：判断“登录且有管理员权限”。


# 五、赋值运算符：变量赋值的简化技巧
赋值运算符用于给变量**赋值**或**更新值**，分为“基础赋值”和“复合赋值”，复合赋值能简化代码，提升可读性。

## 1. 赋值运算符分类与语法
| 运算符 | 名称     | 语法      | 等价写法     | 示例                    |
| ------ | -------- | --------- | ------------ | ----------------------- |
| `=`    | 基础赋值 | `a = b`   | -            | `score = 85`            |
| `+=`   | 加法赋值 | `a += b`  | `a = a + b`  | `score += 5 → score=90` |
| `-=`   | 减法赋值 | `a -= b`  | `a = a - b`  | `score -= 3 → score=82` |
| `*=`   | 乘法赋值 | `a *= b`  | `a = a * b`  | `num *= 2 → num=20`     |
| `/=`   | 除法赋值 | `a /= b`  | `a = a / b`  | `num /= 2 → num=5.0`    |
| `//=`  | 整除赋值 | `a //= b` | `a = a // b` | `num //= 3 → num=3`     |
| `%=`   | 取模赋值 | `a %= b`  | `a = a % b`  | `num %= 3 → num=1`      |
| `**=`  | 幂赋值   | `a **= b` | `a = a ** b` | `num **= 2 → num=100`   |

## 2. 实操示例
```python
# 基础赋值
score = 85
print(f"初始成绩：{score}")  # 输出：85

# 复合赋值
score += 5  # 加分5分
print(f"加分后：{score}")    # 输出：90

score -= 3  # 减分3分
print(f"减分后：{score}")    # 输出：87

num = 10
num *= 2    # 乘以2
print(f"乘以2后：{num}")     # 输出：20

num /= 4    # 除以4
print(f"除以4后：{num}")     # 输出：5.0

# 复合赋值也适用于字符串/列表
s = "Hello"
s += " Python"
print(f"字符串拼接：{s}")    # 输出：Hello Python

lst = [1,2]
lst *= 3
print(f"列表重复：{lst}")    # 输出：[1,2,1,2,1,2]
```

## 3. 核心避坑要点
### 坑1：未定义变量就使用复合赋值
- 报错：`NameError: name 'x' is not defined`；
- 原因：`x += 5`（x未定义，无法执行`x = x +5`）；
- 解决：先基础赋值，再复合赋值：`x = 0; x +=5`。

### 坑2：复合赋值的类型问题
- 报错：`TypeError: unsupported operand type(s) for +=: 'int' and 'str'`；
- 原因：`score = 85; score += "5"`（整数和字符串无法相加）；
- 解决：统一类型（`score += int("5")`）。

## 4. 适用场景
- 变量初始化：`age = 20`、`name = "张三"`；
- 变量更新：成绩加分、计数（`count +=1`）、数值缩放（`price *= 0.8`）；
- 简化代码：用`score +=5`代替`score = score +5`，更简洁。


# 六、运算符优先级：新手必记规则
当多个运算符出现在同一行时，Python会按“优先级”依次执行，优先级高的先算，优先级低的后算。

## 1. 核心优先级排序（从高到低）
1. 括号 `()`（最高优先级，优先计算括号内的表达式）；
2. 幂运算 `**`；
3. 算术运算符（`*`/`/`/`//`/`%` > `+`/`-`）；
4. 比较运算符（`==`/`!=`/`>`/`<`/`>=`/`<=`）；
5. 逻辑运算符（`not` > `and` > `or`）；
6. 赋值运算符（`=`/`+=`/`-=`等，最低优先级）。

## 2. 实操示例
```python
# 示例1：算术运算符优先级（先乘除后加减）
print(10 + 5 * 2)  # 输出：20（先算5*2=10，再算10+10）
print((10 + 5) * 2)# 输出：30（括号改变优先级，先算10+5=15）

# 示例2：幂运算优先级
print(2 * 3 **2)   # 输出：18（先算3²=9，再算2*9）
print((2 * 3)** 2)   # 输出：36（先算2*3=6，再算6²）

# 示例3：比较+逻辑运算符优先级
age = 20
score = 85
# 先算比较运算，再算and
print(age >= 18 and score >= 60)  # 输出：True
# 加括号更清晰（推荐）
print((age >= 18) and (score >= 60))  # 输出：True

# 示例4：逻辑运算符优先级（not > and > or）
a = True
b = False
c = True
# 等价于 (not a) or (b and c)
print(not a or b and c)  # 输出：False
```

## 3. 避坑建议
- 新手不用死记优先级，**加括号**是最简单、最不易出错的方式；
- 复杂表达式务必加括号，比如`(age >= 18) and (score >= 60) and (is_vip == True)`，可读性拉满。


# 七、实战案例：学生成绩综合分析程序（整合所有运算符）
```python
# -*- coding: utf-8 -*-
"""
学生成绩综合分析程序
核心知识点：算术/比较/逻辑/赋值运算符 + 运算符优先级
"""
print("===== 学生成绩综合分析系统 =====")

# 1. 初始化数据（赋值运算符）数据格式为列表里面存放字典数据
students = [
    {"name": "张三", "age": 17, "score": 88},
    {"name": "李四", "age": 19, "score": 95},
    {"name": "王五", "age": 18, "score": 58},
    {"name": "赵六", "age": 20, "score": 82}
]
total_score = 0  # 总分
count = 0        # 学生数量
excellent_count = 0  # 优秀学生数（>=90）

# 2. 遍历分析（算术/比较/逻辑运算符）
for student in students:
    name = student["name"]
    age = student["age"]
    score = student["score"]
    
    # 累加总分和计数（赋值运算符）
    total_score += score
    count += 1
    
    # 判断成绩等级（比较+逻辑运算符）
    if score >= 90:
        level = "优秀"
        excellent_count += 1
    elif score >= 60 and age >= 18:  # 成年且及格
        level = "及格（成年）"
    elif score >= 60 and age < 18:   # 未成年且及格
        level = "及格（未成年）"
    else:
        level = "不及格"
    
    # 输出单个学生信息
    print(f"{name}（{age}岁）：{score}分 → {level}")

# 3. 计算平均分（算术运算符）
avg_score = total_score / count if count != 0 else 0

# 4. 输出统计结果（比较运算符）
print("\n===== 统计结果 =====")
print(f"参与统计学生数：{count}人")
print(f"总分：{total_score}分 → 平均分：{avg_score:.2f}分")
print(f"优秀学生数：{excellent_count}人 → 优秀率：{excellent_count/count*100:.1f}%")

# 5. 综合判断（逻辑运算符）
if avg_score >= 80 and excellent_count >= 1:
    print("\n🎉 班级整体成绩优秀！")
elif avg_score >= 60 and excellent_count >= 0:
    print("\n✅ 班级整体成绩达标！")
else:
    print("\n⚠️ 班级整体成绩需提升！")

print("\n===== 程序结束 =====")
```

### 案例核心知识点覆盖
1. 赋值运算符：`total_score += score`、`count +=1` 简化变量更新；
2. 算术运算符：`total_score / count` 计算平均分，`excellent_count/count*100` 计算优秀率；

# 八、常见问题排查（新手避坑指南）
| 报错/问题                                                    | 原因                             | 解决方案                                                 |
| ------------------------------------------------------------ | -------------------------------- | -------------------------------------------------------- |
| `ZeroDivisionError: division by zero`                        | 算术运算中除数为0                | 计算前判断除数是否为0：`if count !=0: avg = total/count` |
| `TypeError: '>' not supported between instances of 'int' and 'str'` | 比较不同类型数据（如`10 > "5"`） | 统一类型：`10 > int("5")`                                |
| `SyntaxError: invalid syntax`（`if score = 60:`）            | 混淆`==`和`=`                    | 比较用`==`：`if score == 60:`                            |
| `NameError: name 'x' is not defined`（`x +=5`）              | 未定义变量就用复合赋值           | 先基础赋值：`x=0; x+=5`                                  |
| `0.1+0.2 == 0.3 → False`                                     | 浮点数精度误差                   | 判断差值：`abs(0.1+0.2 -0.3) < 1e-9`                     |
| 逻辑判断结果不符合预期                                       | 运算符优先级错误                 | 加括号明确优先级：`(age>=18) and (score>=60)`            |


# 九、总结
今天咱们吃透了Python的四大核心运算符，核心要点梳理如下：

1. **算术运算符**：
   - 核心：处理数值计算，支持加减乘除、取模、幂运算，还有字符串/列表的拼接/重复；
   - 避坑：除数不能为0，浮点数注意精度误差，整除向下取整。

2. **比较运算符**：
   - 核心：判断数据关系，返回布尔值，是条件判断的基础；
   - 避坑：区分`==`（比较）和`=`（赋值），不同类型数据不能直接比较。

3. **逻辑运算符**：
   - 核心：组合多条件，实现“且/或/非”判断，有短路求值特性；
   - 避坑：加括号明确优先级，不要用逻辑运算符替代流程控制。

4. **赋值运算符**：
   - 核心：给变量赋值/更新值，复合赋值简化代码；
   - 避坑：先定义变量再用复合赋值，注意类型匹配。

5. **优先级**：
   - 核心规则：括号 > 幂运算 > 算术运算 > 比较运算 > 逻辑运算 > 赋值运算；
   - 避坑：复杂表达式加括号，不用死记优先级。

运算符是Python处理数据和逻辑的“基石”，后续的循环、函数、类都依赖这些基础——建议你修改实战案例（比如添加“补考加分”“筛选未成年优秀学生”），加深对运算符的理解～
