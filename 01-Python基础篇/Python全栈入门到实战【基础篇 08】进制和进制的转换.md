# 一、前置引入：为什么进制转换是底层编程的核心？
你可能会疑惑：“日常用十进制就够了，为啥要学二进制、八进制？”
其实所有计算机程序最终都会被编译为二进制指令执行——比如：
- 你写的`print(10)`，计算机实际处理的是`0b1010`；
- 配置Linux文件权限`chmod 755`，本质是八进制`0o755`转二进制的权限位；
- 网页设置背景色`#FF0000`，是十六进制`0xFF0000`转RGB颜色值。

简单说：
- 不懂二进制，你无法理解计算机的“语言”；
- 不懂八进制/十六进制，你无法简化二进制的书写（比如16位二进制用4位十六进制就能表示）；
- 不懂进制转换，你无法处理硬件交互、数据编码、权限配置等实战场景。

进制转换是Python底层编程的“入门钥匙”，这节内容必须吃透，否则后续的文件操作、网络编程、硬件交互都会受限～


# 二、先认清楚：不同进制在Python中的表示
在Python中，我们可以直接用“前缀+数字”的方式表示不同进制的数值，解释器会自动识别，且参与计算时会统一转为十进制处理。

## 1. 不同进制的字面量语法
| 进制类型 | 前缀      | 示例        | 说明                       |
| -------- | --------- | ----------- | -------------------------- |
| 十进制   | 无前缀    | `100`       | 日常使用的默认进制         |
| 二进制   | `0b`/`0B` | `0b1100100` | 仅包含0和1                 |
| 八进制   | `0o`/`0O` | `0o144`     | 仅包含0-7                  |
| 十六进制 | `0x`/`0X` | `0x64`      | 包含0-9和A-F（大小写均可） |

## 2. 实操示例
```python
# 不同进制的字面量表示（直接写在代码里）
decimal = 100                # 十进制：无前缀，默认写法
binary = 0b1100100           # 二进制：前缀0b（0B也可）
octal = 0o144                # 八进制：前缀0o（0O也可）
hexadecimal = 0x64           # 十六进制：前缀0x（0X也可）

# 打印结果：所有进制都会自动转为十进制输出
print(f"十进制100 → 直接打印：{decimal}")
print(f"二进制0b1100100 → 直接打印：{binary}")
print(f"八进制0o144 → 直接打印：{octal}")
print(f"十六进制0x64 → 直接打印：{hexadecimal}")
```

**运行结果**：
```
十进制100 → 直接打印：100
二进制0b1100100 → 直接打印：100
八进制0o144 → 直接打印：100
十六进制0x64 → 直接打印：100
```

**关键结论：不管用哪种进制表示，数值的本质不变，Python内部都会以十进制处理。**


# 三、手动转换原理：搞懂进制转换的底层逻辑
手动转换是理解进制本质的核心，咱们逐个拆解最常用的进制转换场景，每一步都配具体例子，新手能跟着一步步算。

## 1. 二进制转十进制
### 原理
二进制的基数是2，从右向左给每个位分配“权重”（2的幂次，从0开始），每个位的数字乘以对应权重，最后求和就是十进制数。

### 步骤
1. 写出二进制数的每一位；
2. 从右向左，给每位标上权重：2⁰、2¹、2²、2³……；
3. 每位数字 × 对应权重；
4. 所有乘积相加，得到十进制数。

### 例子：二进制1011转十进制
```
二进制数：1   0   1   1（从左到右）
对应权重：2³  2²  2¹  2⁰（从左到右，权重从右数0开始）
计算过程：
1×2³ = 1×8 = 8
0×2² = 0×4 = 0
1×2¹ = 1×2 = 2
1×2⁰ = 1×1 = 1
求和结果：8+0+2+1 = 11
```
结论：1011₂ = 11₁₀（下标2表示二进制，10表示十进制）。

## 2. 十进制转二进制
### 原理
把十进制数连续除以2，记录每次的余数，直到商为0，最后从下往上读取余数，就是对应的二进制数。

### 步骤
1. 十进制数 ÷ 2，记录商和余数；
2. 用新的商继续 ÷ 2，记录余数，重复该操作直到商为0；
3. 从最后一个余数开始，倒序排列所有余数。

### 例子：十进制11转二进制
```
11 ÷ 2 = 5  余1
5  ÷ 2 = 2  余1
2  ÷ 2 = 1  余0
1  ÷ 2 = 0  余1
```
从下往上读余数：1 0 1 1 → 结论：11₁₀ = 1011₂（十进制11转为二进制1011）。

## 3. 二进制转八进制
### 原理
八进制的基数是8（2³），1个八进制位对应3个二进制位。把二进制数从右向左每3位分组（不足3位时补0），每组转成十进制数（0-7），就是对应的八进制数。

### 步骤
1. 二进制数从右向左，每3位分一组；
2. 最左边一组不足3位时，在左边补0；
3. 每组二进制数转成十进制数（0-7）；
4. 按顺序组合各组结果。

### 例子：二进制1011101转八进制
```
二进制数：1 0 1 1 1 0 1
从右分组：101（第1组）、011（第2组）、1（第3组，补0成001）
每组转换：
001₂ = 0×2² + 0×2¹ + 1×2⁰ = 1₈
011₂ = 0×2² + 1×2¹ + 1×2⁰ = 3₈
101₂ = 1×2² + 0×2¹ + 1×2⁰ = 5₈
```
组合结果：1 3 5 → 结论：1011101₂ = 135₈（二进制1011101转为八进制135）。

## 4. 八进制转二进制
### 原理
和二进制转八进制相反，1个八进制位转成3位二进制数，最后组合所有二进制位并省略前导零。

### 步骤
1. 把八进制数的每个位单独拆分；
2. 每个位转成3位二进制数（不足3位时左边补0）；
3. 组合所有二进制位，去掉最前面的0。

### 例子：八进制135转二进制
```
八进制位：1   3   5
转二进制：
1₈ = 001₂
3₈ = 011₂
5₈ = 101₂
组合结果：001 011 101 → 001011101
省略前导零：1011101₂
```
结论：135₈ = 1011101₂（八进制135转二进制为1011101）。

## 5. 二进制转十六进制
### 原理
十六进制的基数是16（2⁴），1个十六进制位对应4个二进制位。把二进制数从右向左每4位分组（不足4位时补0），每组转成十进制数（0-15，10-15用A-F表示）。

### 步骤
1. 二进制数从右向左，每4位分一组；
2. 最左边一组不足4位时，在左边补0；
3. 每组转成十进制数（0-15），其中10→A、11→B、12→C、13→D、14→E、15→F；
4. 按顺序组合各组结果。

### 例子：二进制1011101转十六进制
```
二进制数：1 0 1 1 1 0 1
从右分组：1101（第1组）、101（第2组，补0成0101）
每组转换：
0101₂ = 0×2³ + 1×2² + 0×2¹ + 1×2⁰ = 5₁₆
1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 13₁₆ → D
```
组合结果：5 D → 结论：1011101₂ = 5D₁₆（二进制1011101转为十六进制5D）。

## 6. 十六进制转二进制
### 原理
1个十六进制位转成4位二进制数，组合所有二进制位后省略前导零。

### 步骤
1. 拆分十六进制数的每个位；
2. 每个位转成4位二进制数（不足4位时左边补0）；
3. 组合所有二进制位，去掉前导零。

### 例子：十六进制5D转二进制
```
十六进制位：5   D（D=13）
转二进制：
5₁₆ = 0101₂
D₁₆ = 1101₂
组合结果：0101 1101 → 01011101
省略前导零：1011101₂
```
结论：5D₁₆ = 1011101₂（十六进制5D转为二进制1011101）。

## 7. 八进制↔十六进制：以二进制为中介
不管是八进制转十六进制，还是十六进制转八进制，都需要先将原进制转成二进制，再用二进制转目标进制。

### 例子1：八进制135转十六进制
```
第一步：135₈ → 二进制1011101₂（参考前文例子）
第二步：1011101₂ → 十六进制5D₁₆（参考前文例子）
```
结论：135₈ = 5D₁₆。

### 例子2：十六进制5D转八进制
```
第一步：5D₁₆ → 二进制1011101₂（参考前文例子）
第二步：1011101₂ → 八进制135₈（参考前文例子）
```
结论：5D₁₆ = 135₈。


# 四、Python快捷工具：内置函数实现进制转换
手动转换是为了理解原理，实际开发中我们用Python内置函数就能一键转换，无需手动计算。

## 1. 十进制转其他进制
| 目标进制 | 函数    | 作用                                 | 示例（以255为例）         |
| -------- | ------- | ------------------------------------ | ------------------------- |
| 二进制   | `bin()` | 返回带0b前缀的二进制字符串           | `bin(255) → '0b11111111'` |
| 八进制   | `oct()` | 返回带0o前缀的八进制字符串           | `oct(255) → '0o377'`      |
| 十六进制 | `hex()` | 返回带0x前缀的十六进制字符串（小写） | `hex(255) → '0xff'`       |

### 实操示例
```python
# 十进制转其他进制
num = 255

# 转二进制
bin_str = bin(num)
print(f"十进制{num} → 二进制：{bin_str}")

# 转八进制
oct_str = oct(num)
print(f"十进制{num} → 八进制：{oct_str}")

# 转十六进制
hex_str = hex(num)
print(f"十进制{num} → 十六进制：{hex_str}")
```

**运行结果**：
```
十进制255 → 二进制：0b11111111
十进制255 → 八进制：0o377
十进制255 → 十六进制：0xff
```

## 2. 其他进制转十进制
使用`int()`函数，语法：`int(进制字符串, 基数)`
- 进制字符串：可带前缀（如'0b11111111'），也可不带（如'11111111'）；
- 基数：二进制=2，八进制=8，十六进制=16。

### 实操示例
```python
# 其他进制转十进制
# 二进制转十进制（不带前缀）
binary_num = "11111111"
decimal_from_bin = int(binary_num, 2)
print(f"二进制{binary_num} → 十进制：{decimal_from_bin}")

# 八进制转十进制（不带前缀）
octal_num = "377"
decimal_from_oct = int(octal_num, 8)
print(f"八进制{octal_num} → 十进制：{decimal_from_oct}")

# 十六进制转十进制（大写/小写都支持）
hex_num_lower = "ff"
hex_num_upper = "FF"
decimal_from_hex1 = int(hex_num_lower, 16)
decimal_from_hex2 = int(hex_num_upper, 16)
print(f"十六进制{hex_num_lower} → 十进制：{decimal_from_hex1}")
print(f"十六进制{hex_num_upper} → 十进制：{decimal_from_hex2}")
```

**运行结果**：
```
二进制11111111 → 十进制：255
八进制377 → 十进制：255
十六进制ff → 十进制：255
十六进制FF → 十进制：255
```

## 3. 其他进制互转：以十进制为中介
Python没有直接的“二进制转八进制”函数，只需先将原进制转十进制，再转目标进制即可。

### 实操示例
```python
# 二进制转八进制（二进制→十进制→八进制）
binary_str = "1011101"
# 第一步：二进制转十进制
decimal_num = int(binary_str, 2)
# 第二步：十进制转八进制（去掉前缀，取[2:]）
octal_str = oct(decimal_num)[2:]
print(f"二进制{binary_str} → 八进制：{octal_str}")

# 十六进制转二进制（十六进制→十进制→二进制）
hex_str = "5D"
decimal_num = int(hex_str, 16)
binary_str = bin(decimal_num)[2:]
print(f"十六进制{hex_str} → 二进制：{binary_str}")
```

**运行结果**：
```
二进制1011101 → 八进制：135
十六进制5D → 二进制：1011101
```


# 五、进阶技巧：格式化输出不同进制
用f-string可以灵活控制进制的输出格式（带/不带前缀、大小写），比直接使用`bin()`/`oct()`/`hex()`更灵活。

## 1. 常用格式化符号
| 格式化代码 | 意义                           | 示例（num=42） |
| ---------- | ------------------------------ | -------------- |
| `{num:d}`  | 十进制输出                     | `42`           |
| `{num:b}`  | 二进制输出（不带前缀）         | `101010`       |
| `{num:o}`  | 八进制输出（不带前缀）         | `52`           |
| `{num:x}`  | 十六进制输出（小写，不带前缀） | `2a`           |
| `{num:X}`  | 十六进制输出（大写，不带前缀） | `2A`           |
| `{num:#b}` | 二进制输出（带0b前缀）         | `0b101010`     |
| `{num:#o}` | 八进制输出（带0o前缀）         | `0o52`         |
| `{num:#x}` | 十六进制输出（小写，带0x前缀） | `0x2a`         |

## 2. 实操示例
```python
# 格式化输出不同进制
num = 42

# 基础格式化（不带前缀）
print(f"十进制：{num:d}")      # 十进制
print(f"二进制：{num:b}")      # 二进制
print(f"八进制：{num:o}")      # 八进制
print(f"十六进制（小写）：{num:x}")    # 十六进制小写
print(f"十六进制（大写）：{num:X}")    # 十六进制大写

# 带前缀的格式化
print("-" * 20)
print(f"二进制（带前缀）：{num:#b}")     # 带0b
print(f"八进制（带前缀）：{num:#o}")     # 带0o
print(f"十六进制（带前缀）：{num:#x}")   # 带0x
```

**运行结果**：
```
十进制：42
二进制：101010
八进制：52
十六进制（小写）：2a
十六进制（大写）：2A
--------------------
二进制（带前缀）：0b101010
八进制（带前缀）：0o52
十六进制（带前缀）：0x2a
```


# 六、核心避坑要点
| 问题类型           | 具体表现                                                  | 原因                                                    | 解决方案                                                     |
| ------------------ | --------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| `int()`转换报错    | `ValueError: invalid literal for int() with base 2: '12'` | 二进制字符串中出现非0/1的字符，或基数与字符串类型不匹配 | 确保字符串仅包含对应进制的合法字符（二进制0/1、八进制0-7、十六进制0-9/A-F） |
| 类型混淆报错       | `bin(255) + 10` 报错（TypeError）                         | `bin()`返回字符串，无法直接和数字相加                   | 先转十进制再计算：`int(bin(255), 2) + 10`                    |
| 十六进制大小写问题 | 实际开发需要大写但`hex()`返回小写                         | Python内置`hex()`默认返回小写                           | 用`upper()`转换：`hex(255)[2:].upper()` → 'FF'               |
| 前缀处理错误       | 想去掉进制前缀但索引错误                                  | 不了解前缀固定为2位                                     | 去掉前缀直接取`[2:]`，如`bin(255)[2:]`                       |


# 七、实战案例：多进制转换工具
咱们用简单的输入输出，制作一个“十进制↔二进制↔十六进制”的交互式工具，无需自定义函数，纯流程实现：

```python
# 交互式多进制转换工具
print("===== Python多进制转换工具 =====")

# 选择转换方向
choice = input("请选择转换方向：\n1：十进制转二进制/十六进制\n2：二进制转十进制\n3：十六进制转十进制\n请输入数字（1/2/3）：")

if choice == "1":
    # 十进制转二进制/十六进制
    dec_num = input("请输入十进制数：")
    dec_num = int(dec_num)
    # 格式化输出
    bin_str = f"{dec_num:#b}"
    hex_str_upper = f"{dec_num:#X}"
    print(f"十进制{dec_num} → 二进制：{bin_str}")
    print(f"十进制{dec_num} → 十六进制（大写）：{hex_str_upper}")

elif choice == "2":
    # 二进制转十进制
    bin_num = input("请输入二进制数（无需带0b前缀）：")
    # 验证合法性
    is_valid = True
    for char in bin_num:
        if char not in ["0", "1"]:
            is_valid = False
            break
    if is_valid:
        dec_num = int(bin_num, 2)
        print(f"二进制{bin_num} → 十进制：{dec_num}")
    else:
        print("输入错误！二进制数只能包含0和1！")

elif choice == "3":
    # 十六进制转十进制
    hex_num = input("请输入十六进制数（无需带0x前缀，支持大小写）：")
    # 验证合法性
    valid_chars = "0123456789ABCDEFabcdef"
    is_valid = True
    for char in hex_num:
        if char not in valid_chars:
            is_valid = False
            break
    if is_valid:
        dec_num = int(hex_num, 16)
        print(f"十六进制{hex_num} → 十进制：{dec_num}")
    else:
        print("输入错误！十六进制数只能包含0-9和A-F（大小写）！")

else:
    print("输入错误！请选择1、2或3！")
```

### 运行示例1（十进制转二进制/十六进制）
```
===== Python多进制转换工具 =====
请选择转换方向：
1：十进制转二进制/十六进制
2：二进制转十进制
3：十六进制转十进制
请输入数字（1/2/3）：1
请输入十进制数：42
十进制42 → 二进制：0b101010
十进制42 → 十六进制（大写）：0X2A
```

### 运行示例2（二进制转十进制）
```
===== Python多进制转换工具 =====
请选择转换方向：
1：十进制转二进制/十六进制
2：二进制转十进制
3：十六进制转十进制
请输入数字（1/2/3）：2
请输入二进制数（无需带0b前缀）：101010
二进制101010 → 十进制：42
```

# 八、常见问题排查
| 报错/问题                                                 | 原因                               | 解决方案                                      |
| --------------------------------------------------------- | ---------------------------------- | --------------------------------------------- |
| `ValueError: invalid literal for int() with base 2: '12'` | 二进制字符串包含非0/1字符          | 检查并修正字符串，仅保留0和1                  |
| `TypeError: can only concatenate str (not "int") to str`  | 进制函数返回的字符串和数字直接拼接 | 先将数字转字符串：`bin(42) + " → " + str(42)` |
| `SyntaxError: invalid token`（如`0b123`）                 | 二进制字面量包含非法字符           | 二进制只能写0和1，修正为`0b101`               |
| 格式化输出前缀错误                                        | 误用`{num:B}`（大写B）             | 二进制格式化只能用小写`b`：`{num:b}`          |


# 九、总结
今天咱们吃透了进制转换的核心知识，关键要点梳理如下：

1. **进制表示**：
   - Python中二进制带`0b`、八进制带`0o`、十六进制带`0x`前缀，内部统一按十进制处理；
   - 不同进制只是数值的不同书写形式，本质值不变。

2. **手动转换原理**：
   - 二进制↔十进制：权重相乘求和 / 除2取余倒序；
   - 二进制↔八进制：3位分组转换；
   - 二进制↔十六进制：4位分组转换；
   - 八进制↔十六进制：以二进制为中介。

3. **Python快捷工具**：
   - 十进制转其他进制：`bin()`/`oct()`/`hex()`；
   - 其他进制转十进制：`int(字符串, 基数)`；
   - 其他进制互转：以十进制为中介。

4. **格式化输出**：
   - 用f-string的`{num:b}`/`{num:o}`/`{num:x}`灵活控制输出格式；
   - 带前缀用`{num:#b}`/`{num:#o}`/`{num:#x}`。

进制转换是编程的底层基础，虽然日常开发中直接手动计算的场景较少，但理解原理能帮你搞懂计算机的数值存储逻辑。建议你多动手尝试不同数值（如255、42、128）的转换，熟悉流程，为后续的位运算、底层开发打下坚实基础～

下一节，咱们会学习「Python位运算」——基于二进制的特殊运算，是优化代码性能、处理底层数据的核心技巧，结合本节的进制知识，你能彻底搞懂计算机的“位级操作”～
