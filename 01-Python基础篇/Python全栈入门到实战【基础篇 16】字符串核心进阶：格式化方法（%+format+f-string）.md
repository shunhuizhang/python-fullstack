# Python全栈入门到实战【基础篇 16】字符串核心进阶：格式化方法（%/format/f-string）

在Python编程中，拼接或格式化字符串是高频操作——比如输出用户信息、生成动态文本、拼接带变量的日志内容等。直接用`+`拼接字符串不仅代码冗余，还容易出现类型不匹配问题，而Python提供的字符串格式化方法能高效解决这类问题。

本节系统讲解Python中4种主流的字符串格式化方法，覆盖所有实用场景：
- 百分号（%）格式化：传统格式化方式，兼容早期Python版本；
- str.format()方法：进阶格式化方式，灵活性更高；
- f-string（格式化字符串字面值）：Python3.6+推荐用法，简洁且高效；
- 模板字符串（string.Template）：安全场景下的格式化方式；
- 各方法对比：适用场景、性能、可读性分析，以及避坑要点。

掌握字符串格式化后，你能轻松构建动态文本，避免类型拼接错误，同时让代码更简洁易维护。

## 一、前置引入：为什么需要字符串格式化？
直接使用`+`拼接字符串存在明显弊端：
```python
# 问题1：类型不匹配（整数无法直接与字符串拼接）
name = "张三"
age = 20
# print("姓名：" + name + "，年龄：" + age)  # TypeError: can only concatenate str (not "int") to str

# 问题2：代码冗余（多变量拼接时可读性差）
math_score = 85
english_score = 92
print("姓名：" + name + "，数学成绩：" + str(math_score) + "，英语成绩：" + str(english_score))
```

字符串格式化的核心价值：
1. **类型兼容**：自动处理数字、列表等非字符串类型的转换，无需手动`str()`；
2. **代码简洁**：集中管理变量与文本结构，避免冗长的`+`拼接；
3. **格式可控**：精准控制数字精度、对齐方式、填充字符等（如保留2位小数、右对齐）；
4. **可读性强**：文本模板与变量分离，逻辑更清晰。

## 二、核心方法1：百分号（%）格式化（传统方式）
百分号格式化是Python早期的字符串格式化方式，语法类似C语言的`printf`，至今仍有使用（如老项目兼容）。

### 1. 基础语法
```python
"格式化字符串" % (变量1, 变量2, ...)
```
### 格式符说明（常用）
| 格式符 | 说明                             | 示例                                  |
| ------ | -------------------------------- | ------------------------------------- |
| %s     | 字符串（任意类型都会转为字符串） | "姓名：%s" % "张三" → "姓名：张三"    |
| %d     | 整数（十进制）                   | "年龄：%d" % 20 → "年龄：20"          |
| %f     | 浮点数（默认保留6位小数）        | "成绩：%f" % 85.5 → "成绩：85.500000" |
| %.nf   | 浮点数（保留n位小数）            | "成绩：%.1f" % 85.5 → "成绩：85.5"    |
| %x     | 整数（十六进制）                 | "十六进制：%x" % 10 → "十六进制：a"   |

### 2. 核心示例
#### 示例1：基础变量格式化
```python
name = "张三"
age = 20
score = 85.5

# 单个变量
print("姓名：%s" % name)  # 姓名：张三
# 多个变量（需用元组包裹）
print("姓名：%s，年龄：%d，成绩：%.1f" % (name, age, score))  # 姓名：张三，年龄：20，成绩：85.5
```

#### 示例2：格式控制（对齐、填充）
```python
# 右对齐（宽度10，不足补空格）
print("数字：%10d" % 123)  # 数字：       123
# 左对齐（宽度10，不足补空格）
print("数字：%-10d" % 123)  # 数字：123       
# 补零（宽度5，不足补0）
print("数字：%05d" % 123)  # 数字：00123
```

### 3. 优缺点
- **优点**：兼容所有Python版本，语法简单易记；
- **缺点**：不支持参数重排、格式控制能力有限、多变量时可读性下降。

## 三、核心方法2：str.format()方法（进阶方式）
`str.format()`是Python2.6+引入的格式化方法，弥补了百分号格式化的不足，灵活性更高。

### 1. 基础语法
```python
# 方式1：按位置匹配
"格式化字符串".format(变量1, 变量2, ...)

# 方式2：按名称匹配（推荐，可读性更高）
"格式化字符串".format(键1=值1, 键2=值2, ...)

# 方式3：结合字典（**解包）
"格式化字符串".format(**字典)
```

### 2. 核心示例
#### 示例1：按位置匹配
```python
name = "张三"
age = 20
# 按顺序匹配
print("姓名：{}，年龄：{}".format(name, age))  # 姓名：张三，年龄：20
# 按索引匹配（可重复使用）
print("年龄：{1}，姓名：{0}，再次输出姓名：{0}".format(name, age))  # 年龄：20，姓名：张三，再次输出姓名：张三
```

#### 示例2：按名称匹配
```python
# 直接指定名称
print("姓名：{name}，成绩：{score:.1f}".format(name="李四", score=92.5))  # 姓名：李四，成绩：92.5

# 结合字典（**解包）
user = {"name": "王五", "age": 25, "phone": "13812345678"}
print("姓名：{name}，手机号：{phone}".format(**user))  # 姓名：王五，手机号：13812345678
```

#### 示例3：格式控制（对齐、填充、精度）
```python
# 宽度10，右对齐（默认）
print("数字：{:10d}".format(123))  # 数字：       123
# 宽度10，左对齐
print("数字：{:<10d}".format(123))  # 数字：123       
# 宽度10，居中对齐，填充*
print("数字：{:*^10d}".format(123))  # 数字：***123****
# 浮点数保留2位小数，显示千分位
print("金额：{:,.2f}".format(12345.6789))  # 金额：12,345.68
```

### 3. 优缺点
- **优点**：支持参数重排、名称匹配、复杂格式控制，兼容性好（Python2.6+）；
- **缺点**：多变量时语法略繁琐，不如f-string简洁。

## 四、核心方法3：f-string（Python3.6+推荐）
f-string（格式化字符串字面值）是Python3.6引入的格式化方式，也是目前最推荐的用法——语法最简洁、执行效率最高、可读性最强。

### 1. 基础语法
```python
f"格式化字符串{变量/表达式}"
# 或
F"格式化字符串{变量/表达式}"
```
### 核心特点：
- 直接在`{}`中写入变量或表达式，无需额外传参；
- 支持所有Python表达式（如算术运算、函数调用、字典取值）；
- 格式控制语法与`str.format()`一致，更简洁。

### 2. 核心示例
#### 示例1：基础变量格式化
```python
name = "张三"
age = 20
score = 85.5

# 基础用法
print(f"姓名：{name}，年龄：{age}，成绩：{score}")  # 姓名：张三，年龄：20，成绩：85.5
# 格式控制（保留1位小数）
print(f"成绩：{score:.1f}")  # 成绩：85.5
```

#### 示例2：支持表达式与函数调用
```python
# 算术运算
a = 10
b = 20
print(f"10+20={a+b}，10×20={a*b}")  # 10+20=30，10×20=200

# 函数调用
def get_grade(score):
    return "优秀" if score >= 90 else "良好"

print(f"成绩等级：{get_grade(92)}")  # 成绩等级：优秀

# 字典取值
user = {"name": "李四", "age": 22}
print(f"姓名：{user['name']}，年龄：{user['age']}")  # 姓名：李四，年龄：22
```

#### 示例3：复杂格式控制
```python
# 宽度10，居中对齐，填充*
num = 123
print(f"数字：{num:*^10d}")  # 数字：***123****

# 日期格式化（结合datetime）
import datetime
now = datetime.datetime.now()
print(f"当前时间：{now:%Y-%m-%d %H:%M:%S}")  # 当前时间：2026-01-23 15:30:00

# 布尔值转大写
flag = True
print(f"状态：{flag!s}".upper())  # 状态：TRUE
```

### 3. 优缺点
- **优点**：语法最简洁、执行效率最高（比`str.format()`快30%以上）、支持表达式/函数调用；
- **缺点**：仅支持Python3.6+版本，无法兼容老版本。

## 五、补充方法：模板字符串（string.Template）
`string.Template`是Python标准库提供的格式化方式，语法简单且安全性高（适合处理用户输入的模板，避免注入风险）。

### 1. 基础语法
```python
from string import Template

# 定义模板（$变量名 或 ${变量名}）
template = Template("格式化字符串$变量名")
# 替换变量
result = template.substitute(变量名=值)
```

### 2. 核心示例
```python
from string import Template

# 基础替换
t = Template("姓名：$name，年龄：$age")
result = t.substitute(name="张三", age=20)
print(result)  # 姓名：张三，年龄：20

# 字典替换
user = {"name": "李四", "phone": "13987654321"}
t = Template("姓名：$name，手机号：$phone")
result = t.substitute(**user)
print(result)  # 姓名：李四，手机号：13987654321

# 安全替换（忽略缺失的变量，避免报错）
t = Template("姓名：$name，地址：$address")
result = t.safe_substitute(name="王五")
print(result)  # 姓名：王五，地址：$address
```

### 3. 优缺点
- **优点**：语法简单、安全（避免表达式注入）、适合用户输入的模板；
- **缺点**：功能单一（无格式控制）、执行效率低。

## 六、各格式化方法对比与推荐用法
| 方法            | 语法简洁度 | 执行效率 | 功能丰富度 | 兼容版本      | 推荐场景                 |
| --------------- | ---------- | -------- | ---------- | ------------- | ------------------------ |
| 百分号（%）     | ★★☆☆☆      | ★★★☆☆    | ★★☆☆☆      | Python2+/3+   | 老项目兼容、简单场景     |
| str.format()    | ★★★☆☆      | ★★★☆☆    | ★★★★☆      | Python2.6+/3+ | 需兼容Python2的场景      |
| f-string        | ★★★★★      | ★★★★★    | ★★★★☆      | Python3.6+    | 新项目、日常开发（首选） |
| string.Template | ★★★☆☆      | ★★☆☆☆    | ★☆☆☆☆      | Python2+/3+   | 安全场景（用户输入模板） |

### 核心推荐：
1. 新项目优先使用**f-string**：简洁、高效、功能满足99%的场景；
2. 需兼容Python2时使用**str.format()**；
3. 老项目维护时保留**百分号格式化**，无需强行改造；
4. 处理用户输入的模板时使用**string.Template**，避免注入风险。

## 七、避坑要点
### 1. 百分号格式化的类型匹配问题
百分号格式化要求格式符与变量类型严格匹配，否则报错：
```python
# 错误：%d要求整数，传入浮点数
# print("年龄：%d" % 20.5)  # TypeError: %d format: a real number is required, not float

# 正确：转为整数或用%f
print("年龄：%d" % int(20.5))  # 年龄：20
print("年龄：%f" % 20.5)  # 年龄：20.500000
```

### 2. f-string的引号嵌套问题
`{}`内的字符串引号需与外层f-string的引号错开：
```python
# 错误：外层双引号，内层也用双引号
# print(f"姓名：{"张三"}")  # SyntaxError

# 正确：内层用单引号
print(f"姓名：{'张三'}")  # 姓名：张三
# 或外层单引号，内层双引号
print(F'姓名：{"张三"}')  # 姓名：张三
```

### 3. 格式控制的精度四舍五入问题
浮点数的精度控制会自动四舍五入，需注意数据准确性：
```python
num = 123.456
print(f"{num:.2f}")  # 123.46（四舍五入）
print(f"{num:.1f}")  # 123.5（四舍五入）
```

## 八、实战案例：用户信息格式化输出
需求：整合不同格式化方法，实现用户信息的标准化输出，对比各方法的使用体验。
```python
# 原始用户数据
users = [
    {"name": "张三", "age": 20, "score": 85.5, "phone": "13812345678"},
    {"name": "李四", "age": 25, "score": 92.8, "phone": "13987654321"},
    {"name": "王五", "age": 22, "score": 78.3, "phone": "13711112222"}
]

print("===== 百分号格式化 =====")
for user in users:
    print("姓名：%s，年龄：%d，成绩：%.1f，手机号：%s" % (user["name"], user["age"], user["score"], user["phone"]))

print("\n===== str.format()格式化 =====")
for user in users:
    print("姓名：{name}，年龄：{age}，成绩：{score:.1f}，手机号：{phone}".format(**user))

print("\n===== f-string格式化（推荐） =====")
for user in users:
    print(f"姓名：{user['name']}，年龄：{user['age']}，成绩：{user['score']:.1f}，手机号：{user['phone']}")

print("\n===== 模板字符串格式化 =====")
from string import Template
t = Template("姓名：$name，年龄：$age，成绩：$score，手机号：$phone")
for user in users:
    # 先处理成绩精度
    user["score"] = f"{user['score']:.1f}"
    print(t.substitute(**user))
```

## 九、总结
本节系统讲解了Python字符串的4种格式化方法，核心要点梳理如下：
1. **核心方法对比**：
   - f-string（Python3.6+）：简洁、高效、支持表达式，日常开发首选；
   - str.format()：兼容性好、功能丰富，适合需兼容Python2的场景；
   - 百分号格式化：传统方式，仅用于老项目兼容；
   - 模板字符串：安全优先，适合用户输入的模板场景。
2. **格式控制**：对齐、填充、精度等需求可通过`:`后加格式符实现，语法与`str.format()`/f-string通用；
3. **避坑要点**：注意类型匹配、引号嵌套、浮点数四舍五入问题；
4. **推荐原则**：新项目优先用f-string，兼容性需求用str.format()，安全需求用模板字符串。

字符串格式化是Python基础的“高频技能”，后续的函数、推导式、文件操作等场景都会频繁用到，掌握后能大幅提升代码的简洁度与可读性。
