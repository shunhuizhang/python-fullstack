# 一、HTML基本文档结构详解
HTML文档是由一系列嵌套的标签组成的，一个标准的HTML5文档具有固定的结构，我们来逐行拆解上一篇写的Hello World代码：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个前端页面</title>
</head>
<body>
    <h1>Hello World！欢迎来到前端开发的世界！</h1>
    <p>我是一名Python全栈开发者，正在学习前端开发。</p>
</body>
</html>
```

## 1.1 文档声明
```html
<!DOCTYPE html>
```
这是HTML5的文档声明，必须写在HTML文档的第一行，告诉浏览器当前文档使用的是HTML5标准，浏览器会按照HTML5的标准来解析页面。

## 1.2 根标签
```html
<html lang="zh-CN">
</html>
```
`<html>`是HTML文档的根标签，所有其他标签都必须嵌套在`<html>`标签内部。`lang="zh-CN"`属性指定了文档的语言为中文，有助于浏览器和搜索引擎识别页面语言。

## 1.3 头部标签
```html
<head>
</head>
```
`<head>`标签用于存放网页的元信息，这些信息不会显示在页面的主体内容中，主要供浏览器和搜索引擎使用。常见的元信息包括：
- 字符编码设置
- 视口设置
- 网页标题
- 引入外部CSS和JavaScript文件

## 1.4 字符编码设置
```html
<meta charset="UTF-8">
```
设置文档的字符编码为UTF-8，这是目前最通用的字符编码，可以正确显示中文、英文、数字等所有字符。如果不设置这个属性，页面中的中文会出现乱码。

## 1.5 视口设置
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
设置网页的视口，让网页在手机、平板等移动设备上正常显示。`width=device-width`表示视口宽度等于设备屏幕宽度，`initial-scale=1.0`表示初始缩放比例为1.0。

## 1.6 网页标题
```html
<title>我的第一个前端页面</title>
```
`<title>`标签定义了网页的标题，显示在浏览器的标签页上，同时也是搜索引擎抓取页面时的重要信息。

## 1.7 主体标签
```html
<body>
</body>
```
`<body>`标签是网页的主体部分，所有用户能看到的内容（文字、图片、视频、按钮等）都必须写在`<body>`标签内部。

# 二、常用文本标签
文本是网页中最基本的内容，HTML提供了一系列标签来定义不同类型的文本。

## 2.1 标题标签
HTML提供了6级标题标签，从`<h1>`到`<h6>`，字号依次减小，重要性依次降低。

**语法格式**：
```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

**实战示例**：
```html
<h1>Python全栈开发</h1>
<h2>后端开发</h2>
<h3>Python基础</h3>
<h3>数据库</h3>
<h2>前端开发</h2>
<h3>HTML</h3>
<h3>CSS</h3>
```

## 2.2 段落标签
`<p>`标签用于定义段落，段落之间会自动添加上下间距。

**语法格式**：
```html
<p>这是一个段落。</p>
```

# 三、图片标签

`<img>`标签用于在网页中插入图片，是自闭合标签。

## 3.1 核心属性
| 属性     | 作用           | 说明                                                        |
| -------- | -------------- | ----------------------------------------------------------- |
| `src`    | 指定图片的路径 | 必选属性，没有这个属性图片无法显示                          |
| `alt`    | 图片的替代文本 | 当图片无法显示时，会显示这个文本，同时有助于SEO和无障碍访问 |
| `title`  | 图片的提示文本 | 当鼠标悬停在图片上时，会显示这个文本                        |
| `width`  | 图片的宽度     | 单位是像素，只设置宽度时，高度会自动按比例缩放              |
| `height` | 图片的高度     | 单位是像素，不建议同时设置宽度和高度，会导致图片变形        |

## 3.2 路径问题
`src`属性指定图片的路径，路径分为两种：相对路径和绝对路径。

### 相对路径
相对路径是相对于当前HTML文件的路径，是最常用的路径方式。
- 同一级目录：直接写文件名，如`logo.png`
- 下一级目录：`文件夹名/文件名`，如`images/logo.png`
- 上一级目录：`../文件名`，如`../logo.png`

### 绝对路径
绝对路径是完整的网络地址，如`https://www.example.com/images/logo.png`，用于引用网络上的图片。

## 3.3 实战示例
```html
<!-- 同一级目录的图片 -->
<img src="avatar.jpg" alt="头像" title="我的头像" width="200">

<!-- images文件夹下的图片 -->
<img src="images/guaidao.png" alt="横幅" width="200px" height="400px">

<!-- 网络图片 -->
<img src="https://www.python.org/static/img/python-logo.png" alt="Python Logo" width="200">
```

# 四、超链接标签

`<a>`标签用于定义超链接，点击超链接可以跳转到其他页面、文件或页面的指定位置。

## 4.1 核心属性
| 属性     | 作用               | 说明                                                         |
| -------- | ------------------ | ------------------------------------------------------------ |
| `href`   | 指定跳转的目标地址 | 必选属性                                                     |
| `target` | 指定链接的打开方式 | - `_self`：在当前窗口打开（默认）<br>- `_blank`：在新窗口打开 |

## 4.2 链接类型
### 1. 外部链接
跳转到其他网站的页面，需要写完整的网络地址。

```html
<a href="https://www.baidu.com" target="_blank">百度一下</a>
```

### 2. 内部链接
跳转到同一个网站的其他页面，写相对路径即可。

```html
<a href="about.html">关于我们</a>
```

### 3. 空链接
点击后不跳转任何地方，用于占位。

```html
<a href="javascript:;">空链接</a>
```

> ⚠️ 注意：不要写`href="#"`，这会跳转到页面顶部，正确的空链接写法是`href="javascript:;"`。

### 4. 锚点链接
跳转到当前页面的指定位置，需要给目标元素添加`id`属性，然后`href`属性写`#id`。

```html
<!-- 锚点 -->
<h2 id="contact">联系方式</h2>

<!-- 跳转到锚点 -->
<a href="#contact">跳转到联系方式</a>
```

## 4.3 实战示例
```html
<!-- 外部链接，新窗口打开 -->
<a href="https://blog.csdn.net/zsh_1314520" target="_blank">我的CSDN博客</a>

<!-- 内部链接 -->
<a href="index.html">返回首页</a>

<!-- 锚点链接 -->
<a href="#skill">查看我的技能</a>

<h2 id="skill">我的技能</h2>
<p>Python、MySQL、HTML、CSS、JavaScript</p>
```

# 五、综合实战：个人介绍页面

```html
    <meta charset="UTF-8">

    <p>拥有多年开发经验，擅长后端接口开发、数据库设计和前端页面开发，能够独立完成完整的Web项目开发。</p>

    <h3>个人头像</h3>

    <hr>

    <h3>技能列表</h3>
    <p>后端：Python、Django、Flask、FastAPI</p>
    <p>数据库：MySQL、Redis</p>
    <p>前端：HTML、CSS、JavaScript、Vue3</p>
```

# 六、常见误区与避坑指南

1.  **标签不闭合**：HTML标签必须正确闭合，非自闭合标签要有开始标签和结束标签，自闭合标签要写对格式。
2.  **标签大小写问题**：HTML标签不区分大小写，但推荐统一使用小写，这是行业规范。
3.  **路径错误**：图片不显示90%都是路径错误导致的，要仔细检查相对路径是否正确。
4.  **滥用标题标签**：一个页面只能有一个`<h1>`标签，不要用标题标签来设置文字大小，文字大小应该用CSS来控制。
5.  **忘记写alt属性**：`alt`属性是图片标签的重要属性，不仅在图片无法显示时有用，还有助于SEO和无障碍访问。
6.  **错误的空链接写法**：不要写`href="#"`，会跳转到页面顶部，正确的写法是`href="javascript:;"`。
